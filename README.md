# 🌙 Lunar Calendar — Moon phase tracker in 4 languages

A simple console/web application that calculates and displays the current **moon phase** (new moon, waxing crescent, first quarter, waxing gibbous, full moon, waning gibbous, last quarter, waning crescent) based on a given date.

## 🚀 Languages & Run

| Language | File | Run command |
|:---|:---|:---|
| Python | `python/lunar.py` | `python lunar.py` |
| JavaScript | `javascript/lunar.html` | Open in browser |
| C++ | `cpp/lunar.cpp` | `g++ lunar.cpp -o lunar && ./lunar` |
| Go | `go/lunar.go` | `go run lunar.go` |

## 📅 How it works

The program uses an astronomical algorithm to calculate the moon phase for:
- current date (by default) or
- a user-provided date (YYYY-MM-DD)
